Task-02: Stopwatch Web Application

A simple, responsive, and interactive Stopwatch Web Application built using HTML, CSS, and JavaScript.

This project allows users to start, pause, resume, reset the stopwatch, and record multiple lap times.

Project Overview :

The Stopwatch Web Application is designed to accurately measure time intervals through a clean and user-friendly interface.

The application uses JavaScript to control the stopwatch functionality and dynamically display elapsed time and lap records.

Features :
▶️ Start the stopwatch
⏸️ Pause the stopwatch
▶️ Resume the stopwatch
🔄 Reset the stopwatch
🏁 Record lap times
📋 Display multiple lap records
⏱️ Show hours, minutes, seconds, and milliseconds
📱 Responsive design for mobile and desktop
🎨 Modern glassmorphism-style user interface
✨ Smooth button hover effects
📜 Scrollable lap-time history
🛠️ Technologies Used
HTML5 – Creates the structure of the application
CSS3 – Provides styling, responsive design, animations, and layout

How It Works
Start

When the Start button is clicked, JavaScript starts calculating the elapsed time.

Pause

The Pause button stops the timer while keeping the current elapsed time.

Resume

Clicking Start again continues the stopwatch from where it was paused.

Lap

The Lap button records the current stopwatch time and displays it in the lap-time section.

Reset

The Reset button clears the stopwatch and removes all recorded lap times.
